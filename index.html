INTRODUCTION

Smart Home Automation

Smart home systems use sensors and logical conditions to make automatic decisions. Devices such as lights, alarms, fans, heaters and security systems can respond to different conditions detected inside a home.

This project demonstrates how propositional logic can be applied to smart home automation. Each condition is represented by a proposition having either a TRUE or FALSE value, and logical operators are used to determine the appropriate action.

INFERENCE

Rules of Inference

Rules of inference are valid logical methods used to derive a conclusion from given premises.

1. Modus Ponens

If P implies Q and P is true, then Q must be true.

P → Q
P
∴ Q

Example: If smoke is detected, alarm sounds. Smoke is detected. Therefore, the alarm sounds.

2. Modus Tollens

If P implies Q and Q is false, then P must be false.

P → Q
¬Q
∴ ¬P

Example: If smoke is detected, alarm sounds. Alarm is not sounding. Therefore, smoke is not detected.

3. Conjunction

Two true propositions can be combined using AND.

P
Q
∴ P ∧ Q

Example: Motion is detected and it is night.

4. Simplification

If P AND Q is true, either P or Q can be concluded individually.

P ∧ Q
∴ P

Example: Motion is detected AND it is night. Therefore, motion is detected.

5. Hypothetical Syllogism

Two connected implications can be combined to form a new implication.

P → Q
Q → R
∴ P → R

Example: Smoke causes alarm, and alarm causes notification. Therefore, smoke causes notification.

6. Disjunctive Syllogism

If P OR Q is true and P is false, then Q must be true.

P ∨ Q
¬P
∴ Q

Example: The system is either in day mode or night mode. It is not in day mode. Therefore, it is in night mode.

Inference Demonstration: Modus Ponens

Rule: If smoke is detected, the alarm will sound.

Premise 1: S → A
Premise 2: S (Smoke is detected)
Conclusion: ∴ A (Alarm will sound)

Therefore, the conclusion follows by Modus Ponens.

CONCLUSION

Conclusion

Smart home automation can be represented using propositional logic. By converting sensor conditions into TRUE or FALSE propositions, logical operators and rules of inference can be used to determine appropriate actions.

This project demonstrates how mathematical logic can be applied to real-world automated decision-making systems such as smart lighting, security, alarms, temperature control and energy management.
